## Disposition of original findings

1. **P0 graphmap seqfile mutation — fixed.** Cactus v3.3.0 adds `_MINIGRAPH_` to its input seqfile in place. `workflow/scripts/run_minigraph_cactus_stage.py:171–176` now gives graphmap `metadata/seqfile.graphmap.txt`, leaving preflight `seqfile.txt` untouched. Lines 110–154 parse Cactus's modified copy, verify the original path mappings, the `_MINIGRAPH_` path and sole tree leaf, then atomically publish `seqfile.with-minigraph.txt` for split. Lines 277–298 handle an original or already modified copy on restart and protect a copy left before state creation. Cactus's `add_genome_to_seqfile()` checks for an existing tree leaf before adding it, so a repeated export on Toil restart is compatible with this guard. The documented no-tree pangenome seqfile is accepted by Cactus; its SeqFile parser creates a star tree when none is given. The baseline and Cactus-modified path maps are parsed with the same class, avoiding a string-format assumption.

2. **P1 output identity — fixed to the reviewed practical level.** `workflow/scripts/minigraph_cactus_common.py:73–94` records and checks size plus nanosecond modification time for every retained stage product. `run_minigraph_cactus_stage.py:100–107` adds SHA-256 for control files, including both graphmap seqfiles, the split chromfile, split log, split contig-size table, and chromosome seqfiles. Upstream stage checks at lines 239–253 and the no-output verifier at `workflow/scripts/verify_minigraph_cactus.py:35–60` use these records. Large graph/PAF/VG/HAL files are not fully rehashed at every stage; their size and mtime are the documented integrity contract, while original FASTA contents were hashed by preflight.

3. **P1 split QC boundary — fixed.** `run_minigraph_cactus_stage.py:86–91` now requires `chromfile.txt`, `minigraph.split.log`, `contig_sizes.tsv`, and each chromfile-listed seqfile and PAF before publishing the split marker. The pinned split exporter writes exactly those first three names at `<outDir>/`; its chromfile stores three fields, with seqfile/PAF paths formed from `output_dir`. The launcher supplies an absolute `split_dir`, so the chromfile entries are absolute server paths and need no path resolution. `MINIGRAPH_CACTUS_GUIDE.md:21` describes inspection of the split report and ambiguous directory.

4. **P1 preflight speed — fixed.** `workflow/scripts/prepare_minigraph_cactus_seqfile.py:74` uses `bases.translate(None, BASES)` within a streaming scan. [Python's bytes documentation](https://docs.python.org/3/library/stdtypes.html#bytes.translate) confirms that `None` leaves the translation table unchanged and the second argument deletes every allowed base; a nonempty return therefore flags an invalid byte. This removes the per-nucleotide Python loop without loading whole assemblies into memory.

## Remaining server checks and limits

- **Index readability after a `.csi` fallback.** `minigraph_cactus_common.py:58–70` accepts `.tbi` or `.csi` as an output path. The pinned join source can create a CSI index for a contig beyond tabix limits, but its final VCF output dictionary still uses `.tbi` keys. A server pilot should inspect the actual suffix and run a VCF/index readability check; existence alone cannot establish that a fallback index is usable. CHM13's primary chromosomes are below the tabix span, so this is a conditional compatibility concern, not an identified blocker for the configured references.
- **Pilot-dependent HPC settings.** `config/config.yaml:37–75` reserves at most 288 GB for small-node stages and 1,300 GB for fat-node stages, with lower single-machine Toil caps. The 1 TB `disk_mb` setting, profile mapping, local `TMPDIR` capacity, walltime and peak join memory still need measurement on Snellius. `MINIGRAPH_CACTUS_GUIDE.md:7–19` gives server-only checks and pilot commands. The distinct staged build ID and stores isolate the earlier one-shot build; SV-only rules are unchanged.

Proceed with a new-build-ID smoke pilot **on the server** after confirming the pinned Cactus entry-point help and node scratch/profile details. This review does not claim execution success or biological graph acceptance.
